# Nyamuniga Tap

## How do I install these formulae?

`brew install nyamuniga/tap/<formula>`

Or `brew tap nyamuniga/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nyamuniga/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
